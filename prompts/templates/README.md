# Prompt Templates

Reusable prompt fragments and patterns. Reference these in agent prompts
or skill definitions rather than duplicating text.

## Available Templates
- `chain-of-thought.md` — step-by-step reasoning scaffold
- `task-decomposition.md` — break a goal into subtasks
- `critique-and-revise.md` — generate then self-critique output
- `few-shot.md` — example-based formatting guide
